2.4 Session Rotation & Token Refresh
Requirement
The customer's accessToken expires every 15 minutes. The frontend must silently use the 90-day refreshToken to acquire a new access token without interrupting the user's
checkout or browsing experience.
API Contract
Constraints & Security Protocols
Scenario Status Error code Frontend Security Action
Expired Refresh Token (> 90 days) 401 SESSION_EXPIRED Clear local storage / secure store and redirect to login modal.
Revoked Session (Logged out or killed by Admin) 401 SESSION_REVOKED Purge tokens and force re-authentication.
Token Replay Attack (Re-sending an old, already rotated 
refresh token)
401 SESSION_REVOKED Backend auto-revokes the entire device session. Frontend must wipe tokens 
immediately.
